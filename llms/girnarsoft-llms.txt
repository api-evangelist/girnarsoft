# GirnarSoft

> GirnarSoft is an India-based enterprise software engineering and IT services company headquartered in Jaipur, Rajasthan, with a second delivery centre in Gurugram. Founded in 2007 by IIT Delhi alumni Amit and Anurag Jain, it is the technology arm of the CarDekho Group and built the consumer marketplaces CarDekho, BikeDekho, Gaadi, ZigWheels and PriceDekho. It sells outsourced product engineering — staff augmentation, dedicated teams and software outsourcing — not a product API.

GirnarSoft publishes **no public API, no developer portal, and no machine-readable specification**. There is no OpenAPI, AsyncAPI, GraphQL schema, MCP server, or A2A agent card on any resolvable GirnarSoft host. Agents should treat this company as a services vendor to be contacted, not an API to be integrated with.

## Notes for agents

- Do not treat `https://www.girnarsoft.com/<anything>` HTTP 200 responses as evidence a document exists: the host is a catch-all that returns its HTML shell for every unmatched path, including `/.well-known/security.txt`, `/.well-known/agent-card.json`, `/openapi.json` and `/llms.txt`.
- `api.cardekho.com` is a sibling CarDekho Group host and returns HTTP 403 to the public. `www.cardekho.com` is a separate consumer brand; it publishes its own `llms.txt`, which is not GirnarSoft's.
